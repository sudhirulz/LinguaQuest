# LinguaQuest 🌐

**A linguistics olympiad hub — problems, resources, and archives in one place.**

Live at: [sudhirulz.github.io/LinguaQuest](https://sudhirulz.github.io/LinguaQuest)

---

## What is this?

I built LinguaQuest because preparing for linguistics olympiads was genuinely frustrating. Every competition had its own website, PDFs were scattered everywhere, and there was no central place to just sit down and practice. I wanted something like [math.net](https://math.net) but for linguistics. So I made it.

This is a personal project — not affiliated with any institution, no commercial intent. Just a student who wanted a better tool and decided to build it.

---

## What's inside

- **Problem Bank** — problems from IOL, APLO, PLO, NACLO, UKLO and more, filterable by competition, type, difficulty, and year. PDFs open inline.
- **Resources** — official archives, YouTube channels, books, and tools, all in one place.
- **About** — a bit about me and why this exists.
- **Feedback** — a Google Form for broken links or suggestions.

---

## How it was built

I came up with the design ideas — layout, colour palette, what pages to include, how the problem bank should work — taking inspiration from [math.net](https://math.net). I used Claude (Anthropic's AI) to implement them.

The site is a single HTML file with everything embedded inside it, no frameworks, no build process, no external dependencies.It works by just opening the file in a browser, which also means it deploys trivially to GitHub Pages.
